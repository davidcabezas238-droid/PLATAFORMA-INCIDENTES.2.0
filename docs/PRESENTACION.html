Rutas, controladores, validaciones y middleware JWT/roles.

PostgreSQL + Prisma

Persistencia relacional y migraciones versionadas.

Render + Supabase

Aplicación HTTPS; base de datos y bucket privado para adjuntos.

03 · Seguridad

Permisos verificados en el servidor

  • Contraseñas protegidas con hash bcrypt; nunca se devuelven por la API.
  • JWT de una hora; cada petición autenticada vuelve a consultar estado y rol actuales.
  • Solo administradores gestionan cuentas y eliminan incidentes.
  • El sistema conserva al menos un administrador activo.
  • Adjuntos privados servidos tras autenticación; secretos fuera del repositorio.

04 · Calidad y operación

Validar, observar y reconocer límites

Validación

Reglas de entrada en servidor, paginación, permisos y contenido de adjuntos.

Pruebas

ESLint y pruebas de integración con PostgreSQL aislado.

Observabilidad

Logs JSON con ID de solicitud; `/healthz` comprueba PostgreSQL.

Limitaciones

Planes gratuitos pueden suspenderse; sin 2FA, recuperación de contraseña ni alta disponibilidad.

05 · Demostración

Flujo para mostrar en vivo

  • Entrar como administrador y registrar un incidente de prueba.
  • Buscarlo, cambiar su estado y comprobar persistencia tras recargar.
  • Crear/consultar una cuenta y mostrar la restricción del rol técnico.
  • Probar acceso autenticado a un adjunto y consultar el health check.
